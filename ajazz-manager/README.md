# Ajazz Plugin Manager

Графический менеджер плагинов и иконок для Stream Dock AJAZZ.

## Возможности MVP

- автоматически находит Stream Dock AJAZZ и локальную установку Elgato Stream Deck;
- показывает встроенные, Elgato- и уже установленные AJAZZ-плагины;
- устанавливает проверенный порт Twitch одним нажатием;
- сохраняет Twitch-авторизацию при обновлении;
- позволяет экспериментально копировать другие Elgato-плагины;
- принимает произвольную распакованную папку `.sdPlugin`;
- перед заменой или удалением создаёт резервную копию;
- восстанавливает выбранную резервную копию;
- автоматически показывает установленные Elgato `.sdIconPack` и изображения из профилей AJAZZ;
- импортирует PNG, JPG, GIF, BMP, SVG и WEBP в отдельную пользовательскую библиотеку;
- использует системные Fluent-пиктограммы Windows и собственную иконку приложения;
- формирует диагностический отчёт.

## Использование на другом компьютере

1. Установить Stream Dock AJAZZ.
2. Распаковать `Ajazz-Plugin-Manager.zip` целиком — папку `packages` нельзя отделять от EXE.
3. Запустить `AjazzPluginManager.exe`.
4. На вкладке «Плагины» выбрать Twitch и нажать «Установить / обновить».
5. При первой установке подтвердить доступ на официальной странице Twitch.

Приложение не требует прав администратора. Плагины устанавливаются в `%APPDATA%\HotSpot\StreamDock\plugins`, а данные менеджера находятся в `%APPDATA%\AjazzPluginManager`.

## Совместимость

Статус «Проверен» означает, что для плагина есть отдельный рецепт адаптации. «Экспериментальный» выполняет безопасное копирование с резервной копией, но не гарантирует работу интерфейса, авторизации или всех действий.

Статус «Защищён Elgato» используется для DRM-пакетов с бинарным `manifest.json`. Менеджер восстанавливает для списка безопасные метаданные из локализации и версии EXE, но не предлагает обычное копирование: AJAZZ не сможет прочитать такой манифест без отдельного рецепта адаптации.

## Иконки

Менеджер индексирует три источника без лишнего копирования файлов: пользовательскую библиотеку, установленные наборы Elgato и изображения профилей AJAZZ. Выберите иконку, скопируйте её путь и укажите файл в стандартном диалоге AJAZZ. Импортированные пользователем изображения сохраняются отдельно в `%APPDATA%\AjazzPluginManager\IconLibrary`.

## Сборка

```powershell
.\Build-Release.ps1 -ClientId 'PUBLIC_TWITCH_CLIENT_ID'
```

Результат: `release\Ajazz-Plugin-Manager.zip`.

## Распространение

Для публичного распространения следует проверить лицензии оригинальных плагинов и наборов иконок. Долгосрочная модель проекта — распространять менеджер и рецепты адаптации, а оригинальные файлы по возможности брать из локальной официальной установки пользователя.
