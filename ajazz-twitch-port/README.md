# Twitch для Ajazz Stream Dock

Порт официального Twitch plugin Elgato `1.11.6.15` для Stream Dock AJAZZ 2.9 с собственной безопасной авторизацией.

## Что уже работает

- все 16 действий Twitch отображаются в Ajazz;
- `Add New` открывает официальный вход Twitch в браузере;
- используется Device Code Flow без локального веб-сервера и без Client Secret;
- access/refresh token автоматически обновляется;
- отправка сообщений ждёт подтверждения IRC-авторизации Twitch, поэтому первая команда после запуска не теряется;
- перед отправкой проверяется свежесть IRC-соединения; зависший WebSocket и сменившийся access token автоматически приводят к немедленному переподключению;
- токены шифруются Windows DPAPI и читаются только текущим пользователем Windows;
- Node.js находится внутри пакета, поэтому отдельно устанавливать Node или .NET Runtime не нужно;
- установщик сам делает резервную копию старой версии, сохраняет существующую авторизацию, удаляет `auth.bin` из резервных копий и перезапускает Ajazz;
- при первой установке официальный вход Twitch открывается автоматически.

## Один раз для владельца проекта

1. Включите двухфакторную аутентификацию Twitch.
2. Откройте [Twitch Developer Console](https://dev.twitch.tv/console/apps) и зарегистрируйте приложение.
3. Укажите тип клиента `Public`. Это обязательно: `Confidential` потребует Client Secret при обновлении токена и аккаунт перестанет восстанавливаться после истечения access token. В качестве OAuth Redirect URL можно указать `http://localhost:3000` — Device Code Flow его не использует.
4. Скопируйте только `Client ID`. Client Secret создавать, вставлять или отправлять друзьям не нужно.
5. Соберите установщик:

   ```powershell
   .\Build-Release.ps1 -ClientId 'ВАШ_CLIENT_ID'
   ```

Готовый архив появится в `release\Ajazz-Twitch-Installer.zip`.

## Установка для пользователя

1. Распаковать архив.
2. Дважды нажать `Install.cmd`.
3. Подтвердить доступ на автоматически открывшейся странице Twitch.
4. В Ajazz перетащить нужное действие Twitch на кнопку. Если окно входа было закрыто, в настройках действия выбрать `Add New`.

Для полного выхода нажмите `Выйти из Twitch` в настройках любого действия. Плагин отзывает токен у Twitch, удаляет локальный DPAPI-файл и закрывает активные соединения.

Для каждого пользователя создаётся отдельный токен. Он не попадает в архив, `auth-config.json` или настройки Ajazz; на диске находится только DPAPI-зашифрованный файл `data\auth.bin`.

После входа установщик сразу выполняет пробное обновление токена. Так тип `Public` проверяется немедленно, а не через четыре часа или после перезагрузки компьютера. Refresh token публичного Twitch-клиента действует 30 дней без активности; при регулярном запуске он обновляется автоматически.

## Разработка

- `com.elgato.twitch.sdPlugin` — рабочий пакет плагина;
- `launcher\Program.cs` — автономный загрузчик и DPAPI credential helper;
- `patches\Apply-PublicClientRefresh.ps1` — воспроизводимый рецепт проверки и обновления refresh token для Public Client;
- `patches\Apply-IrcReliability.ps1` — ожидание подтверждения IRC-авторизации, keepalive и безопасное переподключение;
- `patches\Apply-IrcLifecycle.ps1` — контроль зависших соединений и синхронизация обновлённого access token;
- `patches\Apply-SecureLogout.ps1` — выход с отзывом токена и очисткой активной сессии;
- `installer` — установщик для Ajazz;
- `Build-Release.ps1` — проверка и сборка ZIP.

Официальная документация: [Device Code Flow](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#device-code-grant-flow), [обновление токенов](https://dev.twitch.tv/docs/authentication/refresh-tokens/), [валидация токенов](https://dev.twitch.tv/docs/authentication/validate-tokens).

## Важно о распространении

В пакете присутствуют файлы официального плагина Elgato. Перед публичной публикацией ZIP или репозитория проверьте условия лицензии/разрешение правообладателя. Для личного использования и передачи знакомому технически достаточно готового архива; для публичного GitHub-релиза безопаснее распространять патчер, который берёт официальный Twitch plugin из локальной установки Elgato.
