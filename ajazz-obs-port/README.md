# OBS Studio для Stream Dock AJAZZ

Импортирует официальные действия OBS Studio из локальной установки Elgato Stream Deck в AJAZZ и включает русский интерфейс. Поддерживаются сцены, коллекции сцен, профили, видимость источников, микшер, медиа, фильтры, стрим, запись, буфер повтора, виртуальная камера и переходы.

Пакет не содержит файлов Elgato. При сборке он читает установленный плагин OBS, создаёт обычный AJAZZ-манифест с русскими названиями и копирует исходники и ресурсы только в локальную папку AJAZZ. Защищённый манифест Elgato не читается и не меняется.

Для работы нужны установленный плагин **OBS Studio** в Elgato Stream Deck и соответствующий плагин Elgato внутри OBS. AJAZZ-порт использует тот же локальный канал OBS, который открывает официальный OBS-плагин Elgato; без OBS-плагина кнопки не смогут подключиться.

## Установка

1. Установи OBS Studio plugin в Elgato Stream Deck и проверь, что Elgato добавил OBS-плагин в OBS.
2. Закрой Stream Dock AJAZZ.
3. Запусти `Install.cmd` или выполни `Install-Plugin.ps1` в PowerShell.
4. В AJAZZ добавь действия из категории OBS Studio.

Установщик сохраняет резервную копию прежнего пакета в `%APPDATA%\AjazzPluginManager\Backups`. Он сохраняет исходные ID действий, поэтому профили Elgato/OBS можно перенести в AJAZZ; пользовательские заголовки в профилях сохраняются.

## Сборка и проверка

```powershell
.\Build-Plugin.ps1
.\tests\Validate-Build.ps1
```

Выходной пакет находится в `build\com.elgato.obsstudio.sdPlugin`. Чтобы собрать архив только с импортёром (без файлов Elgato), выполни `Build-Release.ps1`.
