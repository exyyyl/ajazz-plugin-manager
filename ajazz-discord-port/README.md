# Discord для Stream Dock AJAZZ

Однокликовый импорт официального Discord-плагина Elgato с адаптацией событий AJAZZ.

## Установка

1. Установите официальный Discord-плагин в Elgato Stream Deck.
2. Запустите `Ajazz-Discord-Setup.exe` из GitHub Releases. Если выбран ZIP, распакуйте его целиком и запустите `Install.cmd`.
3. В открытом Discord подтвердите доступ: добавьте действие Discord в AJAZZ и нажмите `Request access` в его настройках.

Установщик берёт оригинальные файлы из `%APPDATA%\Elgato\StreamDeck\Plugins\com.elgato.discord.sdPlugin`. Они не включены в распространяемый пакет. Node.js включён; права администратора не нужны. При обновлении сохраняется резервная копия в `%APPDATA%\AjazzPluginManager\Backups`, локальные данные остаются на месте. Работающий AJAZZ перезапускается.

## Проверено

Авторизация и переключение Mute с физической кнопки в обе стороны подтверждены на устройстве. Доступны 15 действий для кнопок; остальные действия пока экспериментальные. Два действия для энкодеров исключены.

Ajazz передаёт `userDesiredState` даже для обычного нажатия. Адаптер удаляет это поле при `isInMultiAction: false`, возвращая переключение вместо установки конкретного состояния. При отсутствии контроллера в событиях кнопок подставляется `Keypad`. Явное состояние в мультидействиях сохраняется.

## Сборка и разработка

Нужны Windows с .NET Framework, Node.js 22+ и локально установленный оригинальный плагин для проверки импорта.

```powershell
.\Build-Release.ps1
```

Результат: `release\Ajazz-Discord-Setup.exe`, `release\Ajazz-Discord-Installer.zip`, `release\SHA256SUMS.txt`. Сам релиз содержит только наш импортёр, адаптер и Node.js с лицензией. Оригинальный EXE и ресурсы берутся с компьютера пользователя во время установки; защищённый манифест не расшифровывается и не изменяется.

```powershell
# Сборка локального пакета и установка из исходников
.\Build-Plugin.ps1 -Destination '.\build\my-discord.sdPlugin'
.\Install-Plugin.ps1
node --test .\compatibility.test.cjs
```

`bridge.log` содержит типы событий, идентификаторы действий, контроллер, состояние и признаки ошибок; настройки и токены не записываются. Размер журнала ограничен, предыдущая версия хранится в `bridge.log.previous`. Пользовательская авторизация не включается в исходники или релизы.
