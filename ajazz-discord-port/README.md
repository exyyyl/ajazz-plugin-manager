# Discord для Stream Dock AJAZZ

Автономный установщик официального Discord-плагина Elgato с адаптером AJAZZ 1.2.1.

Интерфейс плагина на русском: названия и подсказки действий, состояния,
авторизация, параметры, списки и предупреждения (123 строки). Русский UI
включён независимо от языка, который сообщает AJAZZ. При обновлении стандартные
английские названия существующих действий в профилях заменяются русскими;
пользовательские названия и заголовки сохраняются. Изменяемые профили копируются
в отдельную резервную папку `discord-profiles-*` рядом с резервной копией плагина.

## Установка

1. Запустите `Ajazz-Discord-Standalone-Setup.exe` из GitHub Releases. Если выбран ZIP, распакуйте его целиком и запустите `Install.cmd`.
2. В открытом Discord подтвердите доступ: добавьте действие Discord в AJAZZ и нажмите «Предоставить доступ» в его настройках.

Автономный пакет уже содержит плагин и Node.js; Elgato Stream Deck, отдельная установка Node.js и права администратора не нужны. При обновлении сохраняется резервная копия в `%APPDATA%\AjazzPluginManager\Backups`, локальные данные остаются на месте. Работающий AJAZZ перезапускается. Пользователь предоставляет доступ к своему Discord самостоятельно.

## Проверено

Авторизация и переключение Mute с физической кнопки в обе стороны подтверждены на устройстве. Доступны 15 действий для кнопок; остальные действия пока экспериментальные. Два действия для энкодеров исключены.

Ajazz передаёт `userDesiredState` даже для обычного нажатия. Адаптер удаляет это поле при `isInMultiAction: false`, возвращая переключение вместо установки конкретного состояния. При отсутствии контроллера в событиях кнопок подставляется `Keypad`. Явное состояние в мультидействиях сохраняется.

В 1.2.1 добавляется идентификатор зарегистрированного плагина, если AJAZZ не передал контекст в событии глобальных настроек. Содержимое сохранённых настроек не меняется. Вход после повторной авторизации и перезапуска AJAZZ проверен локально; отозванную или истёкшую сессию Discord может потребоваться подтвердить заново.

## Сборка и разработка

### Автономный установщик

`Build-Release.ps1 -BundleOfficialPlugin` создаёт `Ajazz-Discord-Standalone-Setup.exe`
и ZIP с готовым плагином и Node.js. На компьютере получателя Elgato и оригинальный
Discord-плагин не требуются. Войти в Discord и предоставить доступ нужно каждому
пользователю самостоятельно. Авторизация сборщика в пакет не включается.
Такая сборка содержит оригинальные файлы Elgato; перед публичным распространением
нужно проверить разрешение правообладателя. По умолчанию собирается импортёр.

Нужны Windows с .NET Framework, Node.js 22+ и локально установленный оригинальный плагин для проверки импорта.

```powershell
.\Build-Release.ps1
```

Результат: `release\Ajazz-Discord-Setup.exe`, `release\Ajazz-Discord-Installer.zip`, `release\SHA256SUMS.txt`. Сам релиз содержит только наш импортёр, адаптер и Node.js с лицензией. Оригинальный EXE и ресурсы берутся с компьютера пользователя во время установки; защищённый манифест не расшифровывается и не изменяется.

```powershell
# Сборка локального пакета и установка из исходников
.\Build-Plugin.ps1 -Destination '.\build\my-discord.sdPlugin'
.\Install-Plugin.ps1
node --test .\compatibility.test.cjs
```

`bridge.log` содержит типы событий, идентификаторы действий, контроллер, состояние и признаки ошибок; настройки и токены не записываются. Размер журнала ограничен, предыдущая версия хранится в `bridge.log.previous`. Пользовательская авторизация не включается в исходники или релизы.
