Discord Importer 1.1.0 — русский интерфейс для Stream Dock AJAZZ.

- Однокликовый `Ajazz-Discord-Setup.exe`; альтернативно ZIP с `Install.cmd`.
- Переведены все 123 строки плагина: действия, подсказки, состояния, авторизация, настройки, списки и предупреждения.
- Русский интерфейс включён независимо от языка, который сообщает AJAZZ.
- Стандартные названия уже добавленных действий переводятся автоматически; пользовательские названия и заголовки сохраняются. Перед изменением профилей создаются резервные копии.
- Импорт 15 действий из локальной установки официального Discord-плагина Elgato.
- Исправлено переключение Mute: лишний `userDesiredState` удаляется из обычных нажатий AJAZZ.
- Авторизация и переключение Mute в обе стороны проверены на устройстве. Остальные действия пока экспериментальные.
- При обновлении создаётся резервная копия; локальные данные сохраняются.
- Node.js включён. Администратор и отдельная установка Node.js не требуются.

Перед запуском установите официальный Discord-плагин в Elgato Stream Deck. Откройте Discord, после установки добавьте действие в AJAZZ и подтвердите Request access.

Установщик не содержит оригинального плагина Elgato или пользовательской авторизации. Контрольные суммы приложены в `SHA256SUMS.txt`.
