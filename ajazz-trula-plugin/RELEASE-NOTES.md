Trula для Stream Dock AJAZZ 0.2.0

- Три готовые кнопки: пуск/пауза, музыка на стриме, музыка у стримера.
- Независимые уровни заказов и фонового плейлиста сохраняются при mute и возвращаются повторным нажатием.
- Встроенный WebView2-плеер открывает настоящий HTTPS-адрес Trula. Локальный HTTP-сервер и отдельная док-панель OBS не нужны.
- Общая авторизация вводится один раз и сохраняется в DPAPI-хранилище текущего пользователя Windows.
- Дополнительное действие: громкость, смена трека и настройки Trula.
- Проверены физические кнопки и отдельное отключение источника по API; 26 автономных проверок проходят.

Нужны Windows x64, .NET Framework 4.8 и Microsoft Edge WebView2 Runtime. Для раздельного звука в OBS нужен отдельный источник Trula, а в Trula — вывод «Везде». Захват рабочего стола не должен дублировать звук встроенного плеера.

Ссылки и токены пользователя в пакет не включаются. Обновление сохраняет резервную копию. Интеграция неофициальная и может потребовать обновления при изменениях панели Trula.
