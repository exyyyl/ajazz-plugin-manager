Trula для Stream Dock AJAZZ 0.4.0

- Новое действие «Добавить в очередь [БЕТА]»: выбор музыкальной награды Twitch, предпросмотр ссылки и отправителя последней заявки, добавление по нажатию. «Пропустить заказ» также отмечено как бета.
- Однократная очередь следующих треков использует существующий плеер Trula в OBS. Основной и другие плейлисты не изменяются.
- Защита от повторного добавления заявки, проверка платформы и ID найденного видео, ограничение очереди 30 треками.
- Нужен дополнительный доступ Twitch channel:read:redemptions. Кнопка «Разрешить заявки» находится в аккаунтах. Статусы покупок и баллы не меняются.
- Используются новые заявки после запуска плагина, не старше 30 минут. Заявки во время потери EventSub могут быть пропущены. Для каналов без баллов эта функция недоступна.
- Ускорено и синхронизировано обновление значков громкости, сохранены параметры запуска OBS в пользовательских ярлыках, предупреждение перенесено в свободный угол.
- Плавные переходы статусов, кнопок, полей и подсказок во всех настройках Trula. Неизменившиеся данные не перезапускают анимацию; учитывается настройка уменьшения движения Windows.
- Разрешены пользовательские заголовки для всех кнопок. Обновление значков больше не стирает подпись; для новых кнопок подпись по умолчанию располагается снизу.

Временная очередь основана на очереди следующих треков плеера: ручной выбор другого трека может её очистить. Уже принятые Trula заказы автоматически не распознаются. Добавляйте только те заявки, которые хотите повторно принять вручную. Правила доступности самого видео и поиска Trula сохраняются.

Проверены временное добавление и переход к треку в реальной панели OBS. Получение настоящей заявки Twitch требует нового разрешения и покупки награды зрителем; автоматические тесты используют синтетические события.

Скачайте **Ajazz-Trula-Setup.exe**. Для ZIP распакуйте архив целиком и запустите `Install.cmd`. Контрольные суммы находятся в `SHA256SUMS.txt`.

Авторизация и пользовательские данные в пакет не включены. Обновление сохраняет локальные данные и резервную копию предыдущей установки.
