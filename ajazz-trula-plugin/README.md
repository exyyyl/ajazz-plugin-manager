# Trula для AJAZZ

Четыре действия в категории Trula:

- **Музыка: пуск / пауза** — остановить или продолжить плеер на всех выходах.
- **Звук на стриме** — отключить музыку в источнике Trula для OBS, затем вернуть прежние уровни заказов и плейлиста.
- **Звук у стримера** — то же для встроенного плеера, независимо от источника OBS.
- **Дополнительное управление** — громкость, следующий/предыдущий трек и переключатели Trula.

## Подключение

1. Запустите `Install-Plugin.ps1`. В Ajazz добавьте нужные действия из категории Trula.
2. В настройках любой кнопки вставьте ссылку панели и нажмите «Сохранить и проверить». Подключение общее для всех кнопок; token сохраняется в DPAPI-файле `data/connection.bin` текущего пользователя Windows.
3. Откройте плеер кнопкой «Открыть плеер» в настройках действия. Он загружает настоящую панель Trula в WebView2. Закрытие окна скрывает его, сохраняя музыку; повторно открыть можно той же кнопкой. Другие панели Trula и локальные доки не нужны.
4. Добавьте в сцену **отдельную ссылку источника OBS** из кабинета Trula (`https://trula.io/widgets/source/…`). Ссылка панели не заменяет ссылку источника: у них разные токены.
5. В настройках звука Trula выберите вывод **«Везде»** (панель и источник). Исключите звук встроенного плеера из захвата звука рабочего стола, иначе он продублируется на стриме независимо от состояния источника.

Плеер работает, пока запущен Ajazz. Переключение звука меняет только музыку — уведомления и озвучка донатов не затрагиваются. Состояния и уровни обновляются на кнопках. Плагин не управляет общим микрофоном или всем звуком OBS. На устройстве проверены пуск/пауза и отдельный звук стримера. Физическая кнопка «Звук на стриме» проверена по API: оба уровня источника меняются с 50% на 0%, при этом уровни стримера 5% и 7% сохраняются; после проверки источнику возвращены 50%. Для логики раздельного звука и возврата громкости проходят 26 автономных проверок.

## Сборка

```powershell
.\Build-Plugin.ps1
.\Build-Release.ps1
```

Windows x64/.NET Framework 4.8 и Microsoft Edge WebView2 Runtime (есть в большинстве современных установок Windows). Node.js не нужен. Сборка загружает Microsoft WebView2 SDK 1.0.4314.35 из официального NuGet; библиотеки и лицензии включаются в установщик. Команда запускает проверки раздельного управления, возврата громкости и готовых действий. Для возврата к предыдущей установке используйте резервную копию в `%APPDATA%\AjazzPluginManager\Backups`.

Неофициальная интеграция использует публичный код панели `https://trula.io/cp/` и добавляет компонент управления в её плеер. Настоящий HTTPS-адрес сохраняется, поэтому встроенные видеоплееры получают нормальный контекст сайта. Команды передаются через WebView2 messaging с проверкой адреса страницы; локальный HTTP-сервер не используется. При изменении проверяемой структуры кода Trula загрузка прекращается и адаптер нужно обновить. Оригинальные файлы Trula и пользовательские токены не включаются в репозиторий или установщик. Данные WebView2 хранятся локально в `data/webview`.

Основа — локальный проект `projectDECK` пользователя; расширен готовыми действиями и общим зашифрованным подключением.

`data/commands.log` — ограниченный журнал действий (без token и полных настроек). При экспорте установки не включайте папку `data`: она содержит пользовательские данные WebView2 и подключение. Готовый установщик собирается из списка статических файлов и не включает эту папку.
