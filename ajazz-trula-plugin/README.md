# Trula для AJAZZ

Плагин управляет **существующей док-панелью Trula в OBS**. При запуске StreamDock отдельное окно или второй плеер не создаются. Белые значки на фиолетовом фоне с логотипом Trula отражают состояние воспроизведения и звука. Кнопки уровней показывают 1/2, а изменение громкости — направление и границы MIN/MAX.

- **Аккаунты Trula и Twitch** — подключение и отключение сервисов, запуск OBS.
- **Управление музыкой** — выберите пуск/паузу, предыдущий/следующий трек или «Пропустить заказ [БЕТА]». Пропуск удаляет текущий заказ из очереди без возврата баллов и включает следующий трек; при воспроизведении плейлиста очередь не меняется.
- **Звук на стриме** — отключить музыку в источнике Trula и вернуть прежнюю громкость повторным нажатием.
- **Звук у меня** — то же для док-панели, независимо от источника.
- **Трек в чат** — отправить название текущего трека, ссылку или оба в чат Twitch по нажатию.
- **Добавить в очередь [БЕТА]** — принять последнюю заявку выбранной награды Twitch во временную очередь следующих треков.

Для всех кнопок доступен штатный «Заголовок» StreamDock. Обновления иконки не стирают пользовательскую подпись. В настройках добавлены плавные переходы статусов, полей, кнопок и подсказок; одинаковые обновления не перезапускают анимацию. Учитывается настройка уменьшения движения Windows.

## Громкость

- **Громкость на стриме: два уровня** и **Громкость у меня: два уровня** переключают два заданных значения от 0 до 100%. По умолчанию 50% и 10%. Если текущая громкость отличается от первого уровня, нажатие устанавливает первый; иначе — второй.
- **Громкость: шаг** увеличивает или уменьшает громкость на выбранный шаг 1–100 процентных пунктов. Выберите выход «На стриме» или «У меня» и направление. Результат ограничен диапазоном 0–100%.

Настройки сохраняются при изменении поля. Меняется только музыка заказов и плейлиста выбранного выхода, сохраняя громкость уведомлений и другого выхода.

## Подключение

1. Закройте OBS и установите плагин через `Install-Plugin.ps1`. Один раз подтвердите запрос Windows на установку защиты соединения с OBS. Затем добавьте действия Trula в StreamDock. Если запрос отклонён, управление OBS остаётся отключено; повторите установку с подтверждением.
2. Добавьте действие «Аккаунты Trula и Twitch» и нажмите «Подключить Trula» в настройках. В отдельном окне введите ссылку панели Trula. Ссылка проверяется через API перед сохранением. Она общая для всех кнопок и хранится в зашифрованном DPAPI-файле `data/connection.bin` текущего пользователя Windows.
3. В OBS должна быть одна пользовательская док-панель с настоящей ссылкой `https://trula.io/cp/…` и тем же токеном. Существующую панель заменять не нужно.
4. Запустите OBS кнопкой **«Запустить OBS»** в настройках действия Trula или ярлыком **«OBS Studio — Trula»** на рабочем столе / в меню «Пуск». Ярлык проверяет защиту Windows перед открытием канала управления. Существующие пользовательские ярлыки тоже обновляются, сохраняя параметры профиля, коллекции сцен и другие параметры запуска. Плагин не закрывает работающий OBS и не запускает его автоматически вместе со StreamDock.
5. В сцену добавьте **отдельную ссылку источника OBS** из кабинета Trula (`https://trula.io/widgets/source/…`). У неё собственный токен. Для раздельного звука выберите в Trula вывод **«Везде»**. Не дублируйте звук док-панели через захват рабочего стола.

Параметры отладки вручную добавлять не нужно. Плагин запускает OBS из стандартной папки через защищённый локальный TCP-порт 17936. Постоянные фильтры Windows Filtering Platform разрешают доступ только `TrulaPlugin.exe` из установленной папки под учётной записью, для которой настроена защита. Другие программы и учётные записи блокируются по IPv4 и IPv6. Правила продолжают действовать после закрытия плагина; перед каждым обращением к OBS проверяются их состав, права доступа и состояние. Права администратора при обычной работе не нужны.

Для поиска Windows выбирайте именно **«OBS Studio — Trula»**. Запуск обычного `obs64.exe` без канала управления остаётся обычным запуском OBS: откройте его через новый ярлык, чтобы управлять Trula. Общие ярлыки меню «Пуск» очищаются от старых параметров отладки. Док-панель и сохранённую ссылку менять не нужно. Один фиксированный порт обслуживает одну учётную запись Windows; попытка настроить тот же порт для другого пользователя или другой папки завершится явной ошибкой.

Защита не предназначена для противодействия администратору Windows или вредоносному коду, уже выполняющемуся с правами владельца аккаунта и способному подменять его файлы. Токены по-прежнему хранятся через DPAPI. Если OBS закрыт, панель отсутствует или открыто несколько одинаковых панелей, кнопки показывают ошибку, а второй плеер не создаётся.

## Состояние и команды

Плагин читает состояние из работающего плеера в OBS через локальное соединение. Пуск/пауза и смена трека вызывают команды именно этого плеера. Изменения громкости отправляются в API Trula из той же панели, после чего её настройки перечитываются. При нажатии громкость сразу предварительно отображается на всех связанных кнопках, затем сверяется с ответом OBS. При ошибке показания восстанавливаются или отображается недоступность. Опрос внешних изменений выполняется каждые 500 мс, когда не выполняется команда; время ответа OBS и Trula может увеличить задержку. Искусственной задержки и отбрасывания повторных нажатий нет.

Mute меняет только громкость заказов и плейлиста; уведомления и озвучка донатов не затрагиваются. Громкость для восстановления сохраняется до отключения звука, в том числе между перезапусками StreamDock. Пользовательские нулевые уровни сохраняются. Общий микрофон и прочие источники OBS не меняются.

## Сборка и проверка

```powershell
.\Build-Plugin.ps1
.\Build-Release.ps1
```

Windows x64 и .NET Framework 4.8. WebView2 и Node.js для работы плагина не нужны. Сборка запускает 124 проверки логики. Для проверки адаптера плеера разработчикам доступна команда `node --test tests/obs-player.test.cjs` (14 тестов).

Интеграционная проверка защиты Windows: `tests/Test-ObsGuard.ps1 -ReportDirectory <существующая временная папка>`. Нужны UAC и Планировщик заданий. Тест использует отдельные GUID правил и порт 27936, проверяет IPv4/IPv6, другой exe и тот же exe под LOCAL SERVICE, сохранение правил после закрытия сессии BFE, чтение правил обычным пользователем и отказ при неполном наборе правил. Временная задача и тестовые правила удаляются. Установка защиты выдаёт выбранному пользователю только право OPEN на BFE; права чтения относятся только к объектам Trula, изменение правил остаётся у администраторов/SYSTEM.

На OBS 32.2.2 проверены чтение реального состояния, пуск/пауза с восстановлением исходного состояния, отключение обоих музыкальных выходов по отдельности и восстановление прежней громкости. Проверка клавиш устройства после установки выполняется отдельно.

Интеграция неофициальная: изменения внутренней структуры Trula могут потребовать обновления адаптера. Оригинальные файлы сайта, токены и настройки пользователя в установщик не включаются. Обновление сохраняет резервную копию в `%APPDATA%\AjazzPluginManager\Backups`; папка `data` сохраняется. Старый профиль WebView2 больше не используется и автоматически не удаляется.

`data/commands.log` — ограниченный журнал действий без токенов и полных настроек. Не включайте папку `data` при экспорте установки.

## Трек в чат Twitch

Откройте настройки действия «Аккаунты Trula и Twitch» и нажмите «Подключить Twitch», подтвердите вход на официальном сайте Twitch. Запрашиваются `user:write:chat` для сообщений и `channel:read:redemptions` для заявок. Ранее подключённые аккаунты с доступом только к чату продолжают отправлять сообщения; для заявок нужно нажать «Разрешить заявки». Вход через Device Code Flow не требует Client Secret или отдельно установленного Twitch-плагина. Зарегистрированное публичное OAuth-приложение общее с Twitch-портом проекта; `twitch-config.json` содержит только публичный Client ID. Access/refresh token шифруются DPAPI в `data/twitch.bin`, проверяются перед первым использованием и через час; истекающий access token автоматически обновляется.

Выберите «Название и ссылка», «Только название» или «Только ссылка». Сообщения отправляются только в собственный канал авторизованного пользователя Twitch. Формат автоматически сохраняется при выборе; отдельной кнопки сохранения нет. Формат по умолчанию: `Сейчас играет: название — ссылка`. YouTube и VK получают публичные ссылки; отсутствующее название или ссылка заменяются текстом «Названия нет :C» или «Ссылки нет :C» в выбранном формате. Пустая очередь не создаёт сообщение. Символы перевода строки в названии удаляются; длина сообщения ограничена 500 символами.

Отправка происходит только при нажатии клавиши. Автоматической публикации при смене трека нет. Нажатия выполняются последовательно без искусственной паузы между отправками; ограничения самого Twitch сохраняются. Успех показывается только при `is_sent=true` в ответе Twitch. Неопределённый результат сетевого запроса не повторяется автоматически. Twitch может отклонить сообщение из-за ограничений чата. При Shared Chat пользовательский токен подчиняется стандартному поведению Twitch для общего чата.

Автономно проверены извлечение публичных метаданных трека и форматы сообщений. Реальный вход Twitch и доставка в чат требуют проверки пользователем; при разработке сообщения в чат не публиковались.

Подключение обоих сервисов находится в действии «Аккаунты Trula и Twitch», первом в категории. При подключённом Twitch показаны логин и «Отключить Twitch» вместо входа. Отключение удаляет локальную Twitch-сессию плагина и отменяет незавершённый вход. Оно не сбрасывает Trula. В «Трек в чат» остаётся только выбор формата сообщения.

## Добавить в очередь

1. В «Аккаунты Trula и Twitch» нажмите «Разрешить заявки» и подтвердите дополнительное разрешение channel:read:redemptions на Twitch. Это чтение заявок; кнопка не выкупает награды и не меняет статус покупки за баллы.
2. Перетащите новое действие «Добавить в очередь» на свободную клавишу и выберите музыкальную награду. В списке показаны награды вашего канала, требующие ввода текста. Баллы канала должны быть доступны на вашем Twitch-канале.
3. Дождитесь новой заявки. В настройках кнопки отображается ссылка и отправитель последней заявки выбранной награды. Заявки принимаются после запуска плагина, старые покупки Twitch не перечитываются.
4. Нажмите клавишу, чтобы добавить эту ссылку во временную очередь следующих треков Trula. Текущая музыка не прерывается; если текущего трека нет, начинается воспроизведение очереди. Очередь имеет приоритет перед обычным выбором следующего трека. Основной и другие плейлисты не изменяются.

Поддерживаются HTTPS-ссылки YouTube и VK Видео. Ссылка ищется через штатный поиск Trula; совпадение проверяется по платформе и ID видео. Используйте кнопку для заявок, отклонённых Trula: уже принятые самой Trula заказы автоматически не распознаются и могут быть добавлены повторно по вашему нажатию.

Принимается только последняя заявка выбранной награды, не старше 30 минут. Повторное нажатие не добавляет ту же заявку ещё раз, в том числе после её воспроизведения (сохраняются последние 1000 идентификаторов). В очереди может быть до 30 треков. Это локальная очередь плеера OBS: при ручном выборе другого трека Trula может очистить её как историю следующих треков; она не синхронизируется со сторонними панелями и не превращается в заказ за баллы. Если соединение с EventSub прерывалось, заявки за время отключения могут отсутствовать.

Просмотры и лимиты зрительских наград не проверяются плагином, но недоступные/удалённые видео и ограничения самого поиска/плеера Trula сохраняются. Токены, текст заявок и ссылки не записываются в журнал команд.
