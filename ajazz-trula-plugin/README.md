# Trula для AJAZZ

Плагин управляет **существующей док-панелью Trula в OBS**. При запуске StreamDock отдельное окно или второй плеер не создаются. Белые значки на фиолетовом фоне с логотипом Trula отражают состояние воспроизведения и звука. Кнопки уровней показывают 1/2, а изменение громкости — направление и границы MIN/MAX.

- **Управление музыкой** — выберите пуск/паузу, предыдущий/следующий трек или «Пропустить заказ». Пропуск удаляет текущий заказ из очереди без возврата баллов и включает следующий трек; при воспроизведении плейлиста очередь не меняется.
- **Звук на стриме** — отключить музыку в источнике Trula и вернуть прежнюю громкость повторным нажатием.
- **Звук у меня** — то же для док-панели, независимо от источника.
- **Предыдущий трек** и **Следующий трек** — переключение музыки в панели OBS.
- **Трек в чат** — отправить название текущего трека, ссылку или оба в чат Twitch по нажатию.

## Громкость

- **Громкость на стриме: два уровня** и **Громкость у меня: два уровня** переключают два заданных значения от 0 до 100%. По умолчанию 50% и 10%. Если текущая громкость отличается от первого уровня, нажатие устанавливает первый; иначе — второй.
- **Громкость: шаг** увеличивает или уменьшает громкость на выбранный шаг 1–100 процентных пунктов. Выберите выход «На стриме» или «У меня» и направление. Результат ограничен диапазоном 0–100%.

Настройки сохраняются при изменении поля. Меняется только музыка заказов и плейлиста выбранного выхода, сохраняя громкость уведомлений и другого выхода.

## Подключение

1. Установите плагин через `Install-Plugin.ps1` и добавьте действия Trula в StreamDock.
2. Добавьте действие «Аккаунты Trula и Twitch» и нажмите «Подключить Trula» в настройках. В отдельном окне введите ссылку панели Trula. Ссылка проверяется через API перед сохранением. Она общая для всех кнопок и хранится в зашифрованном DPAPI-файле `data/connection.bin` текущего пользователя Windows.
3. В OBS должна быть одна пользовательская док-панель с настоящей ссылкой `https://trula.io/cp/…` и тем же токеном. Существующую панель заменять не нужно.
4. Закройте OBS и запустите его кнопкой **«Запустить OBS»** в настройках действия Trula. При последующих запусках также используйте эту кнопку. Плагин не закрывает работающий OBS и не запускает его автоматически вместе со StreamDock.
5. В сцену добавьте **отдельную ссылку источника OBS** из кабинета Trula (`https://trula.io/widgets/source/…`). У неё собственный токен. Для раздельного звука выберите в Trula вывод **«Везде»**. Не дублируйте звук док-панели через захват рабочего стола.

Кнопка запускает установленный в стандартную папку OBS с параметрами `--remote-debugging-port=17936 --remote-debugging-address=127.0.0.1`. Их можно добавить в собственный ярлык OBS. Это локальный интерфейс управления браузером OBS; не открывайте этот порт в сеть. Обычный запуск OBS без параметров не подключает управление. Если OBS закрыт, панель отсутствует или открыто несколько одинаковых панелей, кнопки показывают ошибку, а второй плеер не создаётся.

## Состояние и команды

Плагин читает состояние из работающего плеера в OBS через локальное соединение. Пуск/пауза и смена трека вызывают команды именно этого плеера. Изменения громкости отправляются в API Trula из той же панели, после чего её настройки перечитываются. Успех показывается только после подтверждения состояния. Изменения в панели отражаются на кнопках при следующем опросе (обычно до 2 секунд).

Mute меняет только громкость заказов и плейлиста; уведомления и озвучка донатов не затрагиваются. Громкость для восстановления сохраняется до отключения звука, в том числе между перезапусками StreamDock. Пользовательские нулевые уровни сохраняются. Общий микрофон и прочие источники OBS не меняются.

## Сборка и проверка

```powershell
.\Build-Plugin.ps1
.\Build-Release.ps1
```

Windows x64 и .NET Framework 4.8. WebView2 и Node.js для работы плагина не нужны. Сборка запускает 80 проверок логики. Для проверки адаптера плеера разработчикам доступна команда `node --test tests/obs-player.test.cjs`.

На OBS 32.2.2 проверены чтение реального состояния, пуск/пауза с восстановлением исходного состояния, отключение обоих музыкальных выходов по отдельности и восстановление прежней громкости. Проверка клавиш устройства после установки выполняется отдельно.

Интеграция неофициальная: изменения внутренней структуры Trula могут потребовать обновления адаптера. Оригинальные файлы сайта, токены и настройки пользователя в установщик не включаются. Обновление сохраняет резервную копию в `%APPDATA%\AjazzPluginManager\Backups`; папка `data` сохраняется. Старый профиль WebView2 больше не используется и автоматически не удаляется.

`data/commands.log` — ограниченный журнал действий без токенов и полных настроек. Не включайте папку `data` при экспорте установки.

## Трек в чат Twitch

Откройте настройки действия «Аккаунты Trula и Twitch» и нажмите «Подключить Twitch», подтвердите вход на официальном сайте Twitch и разрешение `user:write:chat`. Вход через Device Code Flow не требует Client Secret или отдельно установленного Twitch-плагина. Зарегистрированное публичное OAuth-приложение общее с Twitch-портом проекта; `twitch-config.json` содержит только публичный Client ID. Access/refresh token шифруются DPAPI в `data/twitch.bin`, проверяются перед первым использованием и через час; истекающий access token автоматически обновляется.

Выберите «Название и ссылка», «Только название» или «Только ссылка». Сообщения отправляются только в собственный канал авторизованного пользователя Twitch. Формат автоматически сохраняется при выборе; отдельной кнопки сохранения нет. Формат по умолчанию: `Сейчас играет: название — ссылка`. YouTube и VK получают публичные ссылки; отсутствующее название или ссылка заменяются текстом «Названия нет :C» или «Ссылки нет :C» в выбранном формате. Пустая очередь не создаёт сообщение. Символы перевода строки в названии удаляются; длина сообщения ограничена 500 символами.

Отправка происходит только при нажатии клавиши. Автоматической публикации при смене трека нет. Повторные отправки в один канал ограничены паузой 1 секунда. Успех показывается только при `is_sent=true` в ответе Twitch. Неопределённый результат сетевого запроса не повторяется автоматически. Twitch может отклонить сообщение из-за ограничений чата. При Shared Chat пользовательский токен подчиняется стандартному поведению Twitch для общего чата.

Автономно проверены извлечение публичных метаданных трека и форматы сообщений. Реальный вход Twitch и доставка в чат требуют проверки пользователем; при разработке сообщения в чат не публиковались.

Подключение обоих сервисов находится в действии «Аккаунты Trula и Twitch», первом в категории. При подключённом Twitch показаны логин и «Отключить Twitch» вместо входа. Отключение удаляет локальную Twitch-сессию плагина и отменяет незавершённый вход. Оно не сбрасывает Trula. В «Трек в чат» остаётся только выбор формата сообщения.
