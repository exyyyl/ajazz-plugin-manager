Подключение общее для всех кнопок. Ссылка хранится в зашифрованном файле текущего пользователя Windows.

Плеер откроется в отдельном окне с настоящей панелью Trula. Закрытие окна скрывает его: музыка продолжает работать. Отдельная док-панель Trula в OBS не нужна.

Для раздельного звука выберите в Trula вывод «Везде». В сцену OBS добавьте отдельный источник Trula; звук встроенного плеера не дублируйте захватом рабочего стола.
